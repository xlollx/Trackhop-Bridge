# Code of conduct

Trackhop Bridge follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
like [Trackhop](https://github.com/xlollx/Trackhop/blob/main/CODE_OF_CONDUCT.md).

In short: be kind and patient, assume good faith, keep discussions about the work, and leave out
harassment, insults and personal attacks of any kind. This applies to issues, pull requests,
reviews and every other space of the project.

Report a problem privately to the maintainer through a
[private report](https://github.com/xlollx/Trackhop-Bridge/security/advisories/new) (choose it even
when it is not a security issue). Reports are read by the maintainer only and handled in confidence.
Content or people that break this code may be removed or blocked from the project.
